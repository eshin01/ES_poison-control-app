Seven steps, one human gate

Ingest

PDF, photo, or CSV becomes structured line items with codes

Audit

Eleven deterministic rule families; each finding labeled fact, deduction, or speculation

Benchmark

Medicare rates and the hospital’s own price transparency file

Screen

Poverty level, charity care, 501(r) clocks, No Surprises Act, state law

Plan

Both BATNAs, objective criteria, expected value per dispute, anchor and walk-away

Draft

Records request, dispute, assistance application, settlement offer, scripts

Negotiate

Claude runs the rounds; a person approves every outbound message

Built on the Claude API tool runner: twelve tools, prompt caching, adaptive thinking. The rules engine runs without a model, so every finding is reproducible and unit tested.

The first four steps run with no model at all. The model reads documents, writes to the hospital, and reasons about counteroffers. That split is what makes the findings defensible.
