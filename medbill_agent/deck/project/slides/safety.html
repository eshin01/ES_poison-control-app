Built so it cannot overreach

Human approval on every outbound message

The send tool does not send. It queues the letter and stops. A person reads it, edits it, and releases it. The system prompt tells the model to assume nothing was sent.

Rules before the model

Duplicates, bundling pairs, unit ceilings, date logic, and EOB arithmetic are deterministic code with unit tests. The model never decides whether a code pair conflicts; CMS data does.

Confidence labels and no legal advice

Fact, deduction, or speculation on every finding, carried into the letter. The agent describes rights and cites the rule; it does not bluff, threaten, or practice law.

The hospital is a repeat counterparty for most families. The agent keeps the tone factual and lets the written record carry the pressure, so a win on this bill does not cost the relationship with the people who will treat you next time.

Investors and clinicians both worry about an AI that fights hospitals. The answer is that it files forms and cites rules, under supervision, which is exactly what a good human advocate does.
